## 사용법
1. 제니엘 일자별 실적 업로드 (MMDD 날짜 시트, J열 지역 금액)
2. 코스트코 MX SI 실적 업로드
3. 선택한 기준월의 월별 점별 목표 업로드
4. 상품DB 업로드
5. 보고용 엑셀 생성 클릭

## 제니엘 일자별 실적 집계
- 실적/목표 기준월은 현재 월로 시작하며 원하는 월로 변경할 수 있습니다.
- 선택한 월의 날짜 시트만 합산하고, 배송 금액과 전년동기 금액은 더하지 않습니다.
- B2C경로그룹이 코스트코인 행만 기존 20개 점포 및 담당자에 연결합니다.
- 품목(C열)의 스마트폰, 태블릿, 노트북(PC), 웨어러블(웨어러벌), 버즈, 모바일 액세서리는 CE에서 제외합니다.
- 기존 일자 컬럼형 실적 파일도 선택한 월 기준으로 지원합니다.
- 월별 목표는 해당 월의 기존 양식 파일을 업로드합니다. 매장별 목표 시트의 CC 점포별 CE/MX 목표를 사용합니다.

검증: `node --check app.js`, `node test-import.cjs <원본을 추출한 검증 JSON 경로>`
